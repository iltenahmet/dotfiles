# tmux-config

tmux config for use across machines.

```
git clone git@github.com:iltenahmet/tmux-config.git ~/.config/tmux
```

Pane titles sit on a thick top border, and panes you are not in are greyed out.
The Cmd key bindings that drive tmux live in [ghostty-config](https://github.com/iltenahmet/ghostty-config).
